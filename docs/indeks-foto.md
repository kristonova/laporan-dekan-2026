# Indeks foto dokumentasi untuk presentasi

Untuk mencari foto bagi slide atau web data story, mulai dari [Master Indeks Foto Dokumentasi FMIPA UGM](<../../Dokumentasi Foto/INDEX_FOTO_MASTER.md>).

Indeks mencakup 415 berkas gambar yang diperiksa pada 9 September 2026, dengan katalog per pilar, path asli, deskripsi visual, kata kunci, ukuran/orientasi, catatan tanggal dan duplikat, serta saran foto untuk topik slide. Tautan ke pratinjau dan foto asli tersedia dalam katalog.

Pilih gambar berdasarkan **pesan dan judul slide**, lalu cocokkan nomor dengan versi presentasi. Indeks memisahkan konsep awal 16 slide dari versi `src/pages/presentasi.astro` yang memiliki 18 slide saat pemeriksaan. Periksa file presentasi terkini bila susunannya berubah.

Sebelum memakai gambar, buka file asli dan baca catatan verifikasi. Saat memasangnya ke website, buat aset turunan yang sesuai dan catat ID sumber; path lokal koleksi tidak dapat digunakan langsung sebagai URL publik.
